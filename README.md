# totolab-ni.github.io

Sitio web de **TotoLab** — consultoría y desarrollo de software (Managua, Nicaragua, desde 2025).

- `index.html`: landing page autocontenida (HTML + CSS + JS en línea), bilingüe ES/EN (`?lang=en` fuerza inglés).
- `assets/`: logo y favicon.
- `app-ads.txt`: configuración de anuncios de Google (no borrar).
- Subcarpetas publicadas desde otros repos: `/privacy-my-lottery/`, `/privacy-nica-sol/`.

Textos: el español vive en el HTML; las traducciones al inglés están en el objeto `dict.en` del script al final de `index.html`.

El formulario de contacto no usa servidor: arma el mensaje y lo abre en el correo (`mailto:`) o en WhatsApp.
